# 星織りの庭 — Starweave Sanctuary

Three.js で作った、浮島の庭で星獣を育てるオリジナル3D育成シミュレーション。

## ダウンロードして遊ぶ

[ビルド済みゲーム＋ソース一式のZIPをダウンロード](https://github.com/nisshin1026-coder/-/raw/refs/heads/main/downloads/starweave-sanctuary.zip)

ZIPを展開し、Python 3で `python START_GAME.py`（macOS/Linuxでは `python3 START_GAME.py`）を実行するとブラウザが開きます。Python起動ではnpmインストールは不要です。詳しくはZIP内の「はじめに.txt」をご覧ください。

## 起動

Node.js 22.12+（検証環境24.22）で実行します。

```sh
npm ci
npm run dev -- --port 5173
```

本番ビルドは `npm run build`、確認用サーバーは `npm run preview -- --port 4173`。

## 遊べる内容

- 50体のオリジナル星獣。10系統の体型と、個体ごとの立体装飾・配色・設定。
- 個体別のレベル・経験値・絆・訓練。ごはん、4種の稽古、ふれあい、休息。
- 4つの探索地域、仲間との遭遇、探索で進む全4章の物語。
- 両親を選ぶ星結び。両親の属性を優先した新しい仲間が誕生し、親は残る。
- 10属性：無・火・水・風・地・氷・雷・光・闇・毒。
- 10状態異常：やけど・石化・凍結・麻痺・睡眠・毒・弱化・混乱・気絶・封印。
- 体力・魔力・攻撃・防御・俊敏・命中・回避・魔攻・魔防を使用したターン制バトル。
- 防御、魔力回復、属性相性、物理/魔法、状態異常、敵AI。
- 星貨の商店、日次贈り物、図鑑、全個体の3Dプレビュー。
- ブラウザ内自動保存（localStorage）。外部アカウントやAPIキー不要。

## 描画と物理

手続き生成の草地テクスチャ、PBR素材、影、立体ジオラマ、各個体の装飾。ジャンプは重力・地面衝突・反発・着地変形、耳と尾は減衰ばねを用います。汎用剛体物理エンジンではなく、キャラクター表現に特化した軽量シミュレーションです。モデル・アニメーションは手続き生成で、商用水準の手描きテクスチャや骨格モデルの制作パイプラインは含みません。

## 検証

```sh
npm test
node tests/battle.test.js
node tests/game.test.js
```

ブラウザ確認は別ターミナルで本番プレビューを4173番に起動後、`node tests/browser-check.mjs`。システムChromium `/usr/bin/chromium` を使用し、スクリーンショットは `/tmp/starweave-*.png` に保存します。

## ファイル

- `src/main.js` — 画面と操作
- `src/style.css` — レスポンシブUI
- `src/scene.js` — Three.js、キャラクター造形、物理と演出
- `src/data.js` — 50体、34技、属性・状態異常
- `src/game.js` — 個体別育成、探索、配合、保存、商店
- `src/battle.js` — ターン制戦闘

セーブはこの端末・ブラウザ限定です。オンライン同期、対人対戦、音声、一般的な剛体衝突は未実装です。

## 図鑑画像の再生成

開発サーバーを起動した状態で `node scripts/generate-thumbnails.mjs` を実行すると、50体の実モデルから `public/monsters/*.png` を生成します。部分更新は `--ids=m03,m08`。モデルと図鑑サムネイルを同じ造形で管理できます。

## 品質確認の範囲

独立した批評担当による3回のレビューを実施し、個体別育成、表示と計算の不整合、3D戦闘、50体の識別性、モバイル表示を改善しました。判定は「主要システムを備えた、見た目の整ったオリジナル育成ゲームの初版」です。全2,500組の戦闘終了と35件の機能・データテストを検証しています。長期間プレイでの経済・育成バランスや、商用水準のアセット制作は今後の調整対象です。
